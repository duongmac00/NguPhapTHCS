SO SÁNH HƠN (COMPARATIVES)

1. Lý thuyết ngắn gọn

Dùng để so sánh hai người hoặc hai vật.

Ví dụ:

  • Tom is taller than John.
  • This car is more expensive than that car.

2. Công thức

Tính từ ngắn

S + be + adj-er + than + ...

tall → taller

long → longer

Tính từ dài

S + be + more + adj + than + ...

beautiful → more beautiful

expensive → more expensive

3. Dấu hiệu nhận biết

  • than

Ví dụ:

She is taller than me.

4. Lưu ý quan trọng

big → bigger

hot → hotter

happy → happier

easy → easier

good → better

bad → worse
